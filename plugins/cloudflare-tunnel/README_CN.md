# Cloudflare 快速隧道

一键把 DiceFrame 暴露到公网：启用后生成一个 `https://xxx.trycloudflare.com` 的公网 HTTPS 地址，并自动写入邀请链接，朋友/群聊 Bot 可以直接访问，无需公网 IP、无需域名、无需账号。

## 用法

1. 在"设置 → 插件"中启用本插件。
2. 打开"设置 → 外网接入"，点击"一键启用"（或开启插件的"随宿主启动自动开隧道"）。
3. 等待约 30~60 秒，卡片会显示公网地址；该地址会自动同步到邀请链接。
4. 停止隧道后，访问地址恢复为发布前的状态。

## 两种模式

- **自动模式**：当前核心支持隧道接缝时，公网地址自动写入分享链接，无需手工操作。
- **手动模式**：旧版核心没有隧道接缝（publish 返回 404/403）时，插件保持隧道运行但无法自动写入，请在"设置 → 分享地址"里手动粘贴卡片上显示的地址。

## 说明

- 快速隧道的公网地址**每次启动都会变化**（随机域名），重启后链接会更新。需要固定地址的长团建议使用带固定域名的方案。
- 二进制优先使用随 DiceFrame 安装包分发的 `cloudflared`（离线可用）；未随包分发时自动从官方 GitHub Release 下载。
- 如果手动放置了 `cloudflared` 二进制到插件数据目录的 `bin/` 下，插件会直接使用它而不重新下载（适合离线或企业内网环境）。
